## Delivered scope

- `register_learning_artifact_job` atomically registers only source-level
  `generate_overview`, `translate_segments`, or `explain_selection` jobs with
  bounded private JSON-object input. Conflict replay returns only job ID,
  status, and `created=false`, preserving every public/private field.
- `transition_learning_artifact_failure` locks the exact owner/source/type/
  lease/attempt fence. Attempts 1–4 use exact 1/2/4/8-minute retry clocks;
  attempt 5 cannot retry; attempts 1–5 may terminalize while atomically
  clearing input and preserving result.
- `complete_learning_artifact_job` locks the same exact fence, enforces the
  three frozen job-to-artifact mappings, publishes an idempotent bounded
  owner/source artifact, keeps learner context `en` → `zh-CN`, succeeds the
  job, clears input, and writes strict private result `{artifactId}` in one
  transaction.
- All three functions are original Popcorn SQL, `SECURITY DEFINER`, fixed to
  `search_path=pg_catalog`, revoked from public/anonymous/authenticated roles,
  and granted only to `service_role`. They require explicit user IDs and do no
  global work discovery.
