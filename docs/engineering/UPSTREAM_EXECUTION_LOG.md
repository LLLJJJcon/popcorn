## Task 7 observed execution

- The persistent Chromium fixture loads the absolute `extension/` path using `--disable-extensions-except` and `--load-extension`; Firefox and WebKit are not configured.
- The deterministic YouTube page exercises the real content script and Side Panel DOM. Popcorn transcript, translation, overview, explanation and sync endpoints are fixture-backed; CI makes no real Provider call.
- The sign-in button must be clicked before PKCE state appears. Playwright's Chromium build does not complete the `chrome.identity` auth webview, so the fixture injects the deterministic post-callback session only after the real click/PKCE boundary; `extension/tests/auth.test.js` separately proves verifier/state/code exchange.
- The scenario verifies native Chinese plus lazy English/Bilingual rendering, all six save kinds under one video parent, unchanged playback/navigation, idempotent retry after a dropped acknowledgement, service-worker termination followed by alarm recovery, zero pending events and zero unapproved HTTP origin.
- `tests/integration/capture/cross-user.test.ts` attempts owner-mismatched source, snapshot, segment, saved-item and job access, including a service-role call with the wrong expected user; every path refuses the mismatch.
